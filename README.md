# A Flash Intro to Data Analysis with Python, Marimo and SQL/DuckDB

- Install `uv` if you haven't yet: https://docs.astral.sh/uv/getting-started/installation/
- `git clone https://github.com/rjbudzynski/NWP-SQL-2025L`
- `cd NWP-SQL-2025L && uv sync`
- `uv run marimo edit marimo-flash-intro.py`
- `uv run marimo edit warsaw_temperature_analysis.py`
